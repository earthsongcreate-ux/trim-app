# FINANCIAL DATA INTELLIGENCE SKILL

## PURPOSE
Transform raw financial transactions into structured insights.

## CORE FUNCTIONS
- Detect recurring transactions (subscriptions)
- Categorize spending automatically
- Identify anomalies (price increases, duplicates)
- Track trends over time

## OUTPUT
- Clean categorized transaction data
- Subscription list with confidence scores
- Alerts for unusual changes

## SYSTEM BEHAVIOR
- Prioritize accuracy over speed
- Continuously refine categorization
- Flag uncertainty instead of guessing
