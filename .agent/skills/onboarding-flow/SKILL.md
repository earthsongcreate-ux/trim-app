# ONBOARDING FLOW SKILL

## PURPOSE
Convert new users into activated users within 60 seconds.

## CORE PRINCIPLE
VALUE → THEN FRICTION

Never the other way around.

---

## STRUCTURE

STEP 1: IMMEDIATE VALUE
- Show useful insight instantly (before signup if possible)

STEP 2: PERSONALIZATION
- Ask 2–3 questions max
- Tailor experience immediately

STEP 3: QUICK WIN
- Guide user to first success action

STEP 4: ACCOUNT CREATION (DELAYED)
- Only after value is experienced

STEP 5: PROGRESSIVE DISCLOSURE
- Reveal features gradually

---

## INSPIRATION PATTERNS

- Duolingo → learn before signup
- Wise → show value without commitment
- Slack → guided action immediately
- Instagram → social relevance early

---

## OUTPUT
- Onboarding screen sequence
- Copy + flow logic
- First “aha moment” trigger
